02 — case study

Esaad Card · Dubai Police

A government-grade Android app, built from scratch, where every request has to prove which device sent it.

Problem

A secure government app for Esaad cardholders, with security requirements beyond standard HTTPS.

Approach

Clean Architecture with a Jetpack Compose UI. Mutual SSL with client-side certificates, so the server authenticates the app as well as the app authenticating the server.

Result

Built from scratch and live on Google Play.
